# The Melting Point

An interactive climate memorial kiosk web app about the Nepal August 2026 flood.

- Real-time 3D WebGL terrain visualization with Three.js
- Multi-act story overlays, warming stripes, climate spiral, energy budget and sea-level dashboards
- Multilingual UI (English, Finnish, Swedish)

Built with React, TypeScript and Vite.

## Run locally
```bash
npm install
npm run dev
```
